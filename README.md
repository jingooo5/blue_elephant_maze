# 방탈출 — 피해자의 노트북

정적 HTML + CSS 위주. 빌드 도구·환경변수·서버 없음.
JavaScript는 타이머 하나 때문에 `game.js` 한 파일만 씁니다.

```
index.html    페이지 0 — 시작 화면 (새 게임 시작)
lock.html     페이지 1 — 노트북 잠금화면 (비밀번호 입력)
photo.html    페이지 2 — 전체 화면 사진
styles.css    세 페이지 공용 스타일
game.js       세 페이지 공용 — 타이머 · 뒤로가기 버튼
images/       사진 넣을 폴더 (아직 비어 있음)
```

진행 흐름: `index.html` → (새 게임 시작) → `lock.html` → (비밀번호) → `photo.html`

## 페이지 0 — 시작 화면

제목 `푸른코끼리 · 코낄중학교`, 사이버폭력 예방 주제에 맞춰 파란 톤으로 잡았습니다.

- 코끼리 엠블럼은 **인라인 SVG**라 이미지 파일이 필요 없습니다. 색은
  `styles.css` 의 `--blue` / `--blue-deep` 을 바꾸면 로고·버튼이 같이 바뀝니다.
- 도입 문구 세 줄은 `index.html` 의 `.intro__lead` 에 있습니다. 자유롭게 고치세요.
- 하단 `코낄중학교 학생생활교육부 · 푸른코끼리 캠페인` 도 임의 문구입니다.

## 타이머 · 뒤로가기 (세 페이지 공통)

`game.js` 가 두 요소를 모든 페이지에 붙입니다. HTML 세 곳에 같은 코드를
복사해 둘 필요가 없도록 한 것이라, 모양이나 문구를 바꿀 땐 `game.js` 한 곳만 고치면 됩니다.

**타이머 — 화면 중앙 상단**

- 페이지 0의 `새 게임 시작` 을 누른 순간부터 잽니다.
- **새로고침·페이지 이동·브라우저를 껐다 켜도 이어집니다.** 브라우저 저장소에
  "시작한 시각" 하나만 적어 두고, 화면에 뜨는 숫자는 매번 `지금 - 시작 시각` 으로
  다시 계산합니다. 그래서 탭을 오래 닫아 뒀어도 시간이 밀리지 않습니다.
- 0.1초 단위까지 보여줍니다 (`07:24.6`). 1시간을 넘기면 `1:07:24.6` 으로 늘어납니다.
- `초기화` 오른쪽에 `일시정지` 버튼이 있습니다. 누르면 시간이 그 자리에서 멈추고
  버튼이 `계속` 으로 바뀝니다. 다시 누르면 멈춰 있던 만큼을 건너뛰고 이어서 갑니다
  — 이 상태도 저장소에 남아서 일시정지 중에 새로고침해도 멈춰 있습니다.
- `초기화` 를 눌러야 0으로 지워집니다(일시정지 상태도 함께 풀립니다). 실수 방지로
  확인창이 한 번 뜨고, 확인하면 시작 화면으로 갑니다. **다음 팀 받기 전에 이걸 누르세요.**

**뒤로가기 — 왼쪽 아래**

- 각 페이지 `<body data-prev="...">` 에 적힌 곳으로 갑니다
  (`lock.html` → `index.html`, `photo.html` → `lock.html`).
- 페이지 0에는 `data-prev` 가 없어서 버튼도 안 생깁니다. 페이지를 더 늘릴 땐
  `<body>` 에 `data-prev` 한 줄만 적어 주면 됩니다.
- 진행 중에 페이지 0으로 돌아가면 타이머는 계속 돌고, 시작 버튼 문구가
  `이어서 진행` 으로 바뀝니다. 그때 다시 눌러도 타이머는 초기화되지 않습니다.

> 저장소는 브라우저·기기별로 따로입니다. 진행 노트북과 참가자 노트북이 다르면
> 타이머도 따로 돕니다.

## 비밀번호 바꾸기

`lock.html` 의 `<input>` 에 있는 `pattern` 값 **한 곳**만 고치면 됩니다.

```html
<input class="field__input" type="password" pattern="0721" ...>
```

현재 비밀번호는 `0721` 입니다. 숫자·영문 모두 됩니다 (`pattern="bluesky"`).
자리수를 바꾸면 `lock.html` 아래쪽 힌트 문구(`힌트 · 네 자리 숫자`)도 같이 고쳐 주세요.

자리수는 `pattern` 길이를 보고 `game.js` 가 알아서 맞춥니다. 여섯 자리로 바꾸면
입력칸도 여섯 자까지만 받고, 경고 시점도 여섯 자 기준으로 따라갑니다. **고칠 곳은 `pattern` 한 군데뿐입니다.**

동작 방식:

- 맞으면 → `photo.html` 로 넘어갑니다.
- **자리수를 다 채우고 확인(→)이나 Enter 를 눌러 틀렸을 때만** 입력칸이 빨갛게
  흔들리고 "비밀번호가 올바르지 않습니다. 다시 시도하세요." 가 뜹니다.
- 다시 한 글자라도 입력하면 경고는 바로 사라집니다.
- 자리수를 덜 채우고 눌렀을 때는 아무 반응도 하지 않습니다(경고도, 이동도 없음).
- 브라우저 기본 경고 말풍선은 `<form novalidate>` 로 껐습니다. 판정은 `game.js` 가 합니다.
- `<input>` 에 `name` 이 없어서 주소창에 비밀번호가 남지 않습니다.

> 정적 페이지라 비밀번호는 소스 보기로 확인 가능합니다. 현장 진행용이니 문제없지만,
> 참가자에게 개발자도구가 열린 노트북을 주지는 마세요.

## 이미지 넣기

| 위치 | 파일 | 고칠 곳 |
|---|---|---|
| 페이지 0 배경 | `images/cover.jpg` | `styles.css` 맨 위 `--cover` 한 줄 |
| 페이지 1 바탕화면 | `images/wallpaper.jpg` | `styles.css` 맨 위 `--wallpaper` 한 줄 |
| 페이지 1 계정 사진 | `images/avatar.jpg` | `lock.html` 의 `.avatar` 안에 `<img class="avatar__img" ...>` 추가 |
| 페이지 2 전체 사진 | `images/evidence.jpg` | `photo.html` 의 `<img>` 주석 해제 + 자리표시자 `<div>` 삭제 |

**페이지 0에 어두운 배경 사진을 넣는 경우**: 지금은 흰 배경 기준이라 글씨가 진한 색입니다.
`styles.css` 맨 아래쪽 `--- 어두운 배경 사진을 넣을 때 ---` 주석 블록을 풀면
제목·문구·엠블럼이 밝은 색으로 바뀌고 반투명 어두운 막이 깔립니다.

페이지 2 사진은 기본이 `object-fit: cover`(화면 꽉 채움, 가장자리 잘림)입니다.
잘리면 안 되는 단서면 `styles.css` 의 `.stage__img` 에서 `contain` 으로 바꾸세요.

바탕화면 사진이 어두워도 로그인 패널이 흰 카드라서 글씨는 그대로 잘 보입니다.

## 로컬에서 보기

**반드시 정적 서버로 띄우세요.** 파일을 더블클릭해서 여는 `file://` 방식에서는
브라우저가 저장소를 막는 경우가 있어 타이머가 유지되지 않을 수 있습니다.

```
npx serve .
```

배포된 주소(https)에서는 문제없습니다.

## Vercel 배포

설정 파일이 필요 없습니다. 프레임워크는 **Other**, 빌드 명령은 비워 두면 됩니다.

```
npx vercel        # 미리보기
npx vercel --prod # 실제 배포
```

또는 GitHub 저장소에 올린 뒤 Vercel 대시보드에서 Import 해도 그대로 뜹니다.

## 진행 메모

- 노트북 화면(1280×800 ~ 1440×900) 기준으로 맞췄습니다. 세로 760px 이하에서는 여백이 줄어듭니다.
- 상태 표시줄 시각 `11월 12일 (화) 02:47` 은 연출용 고정값입니다 (시계가 돌면 JS가 필요해서 일부러 멈춰 뒀습니다).
- 메뉴는 없고, 왼쪽 아래 `이전으로` 와 위쪽 `초기화` 두 개가 전부입니다.
- 다음 팀을 받을 땐 `초기화` → 확인. 시작 화면으로 돌아가면서 타이머가 0이 됩니다.
- 키오스크처럼 쓰려면 브라우저를 전체화면(F11 / ⌃⌘F)으로 두면 됩니다.
