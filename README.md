# 방탈출 — 피해자의 노트북

정적 HTML + CSS 위주. 빌드 도구·환경변수·서버 없음.
JavaScript는 타이머 하나 때문에 `game.js` 한 파일만 씁니다.

```
index.html    페이지 0 — 시작 화면 (새 게임 시작)
lock.html     페이지 1 — 노트북 잠금화면 (비밀번호 입력)
photo.html    페이지 2 — 카카오톡 캡처 + 말풍선
page3.html    페이지 3 — 비밀 대화방 잠금화면 (iOS 팝업으로 비밀번호 입력)
page4.html    페이지 4 — 비밀 대화방 공개 (캡처 + 말풍선, 페이지 2와 같은 배치)
page5.html    페이지 5 — 마지막 정답 입력
page6.html    페이지 6 — 범인 지목 (코끼리 4장 중 선택)
page7.html    페이지 7 — 탈출 성공 (내용 최소한만 — 자유롭게 바꾸세요)
styles.css    전 페이지 공용 스타일
game.js       전 페이지 공용 — 타이머 · 뒤로가기 버튼 · 비밀번호/정답 판정
images/       사진 폴더
```

진행 흐름: `index.html` → (새 게임 시작) → `lock.html` → (비밀번호) → `photo.html` →
(다음) → `page3.html` → (비밀번호) → `page4.html` → (다음) → `page5.html` →
(정답) → `page6.html` → (범인 지목) → `page7.html`

## 페이지 0 — 시작 화면

제목 `푸른코끼리 · 코낄중학교`, 사이버폭력 예방 주제에 맞춰 파란 톤으로 잡았습니다.

- 코끼리 엠블럼은 **인라인 SVG**라 이미지 파일이 필요 없습니다. 색은
  `styles.css` 의 `--blue` / `--blue-deep` 을 바꾸면 로고·버튼이 같이 바뀝니다.
- 도입 문구 세 줄은 `index.html` 의 `.intro__lead` 에 있습니다. 자유롭게 고치세요.
- 하단 `코낄중학교 학생생활교육부 · 푸른코끼리 캠페인` 도 임의 문구입니다.

## 타이머 · 뒤로가기 (세 페이지 공통)

`game.js` 가 두 요소를 모든 페이지에 붙입니다. HTML 세 곳에 같은 코드를
복사해 둘 필요가 없도록 한 것이라, 모양이나 문구를 바꿀 땐 `game.js` 한 곳만 고치면 됩니다.

**타이머 — 화면 중앙 상단**

- 페이지 0의 `새 게임 시작` 을 누른 순간부터 잽니다.
- **새로고침·페이지 이동·브라우저를 껐다 켜도 이어집니다.** 브라우저 저장소에
  "시작한 시각" 하나만 적어 두고, 화면에 뜨는 숫자는 매번 `지금 - 시작 시각` 으로
  다시 계산합니다. 그래서 탭을 오래 닫아 뒀어도 시간이 밀리지 않습니다.
- 0.1초 단위까지 보여줍니다 (`07:24.6`). 1시간을 넘기면 `1:07:24.6` 으로 늘어납니다.
- `초기화` 오른쪽에 `일시정지` 버튼이 있습니다. 누르면 시간이 그 자리에서 멈추고
  버튼이 `계속` 으로 바뀝니다. 다시 누르면 멈춰 있던 만큼을 건너뛰고 이어서 갑니다
  — 이 상태도 저장소에 남아서 일시정지 중에 새로고침해도 멈춰 있습니다.
- `초기화` 를 눌러야 0으로 지워집니다(일시정지 상태도 함께 풀립니다). 실수 방지로
  확인창이 한 번 뜨고, 확인하면 시작 화면으로 갑니다. **다음 팀 받기 전에 이걸 누르세요.**

**뒤로가기 — 왼쪽 아래**

- 각 페이지 `<body data-prev="...">` 에 적힌 곳으로 갑니다
  (`lock.html` → `index.html`, `photo.html` → `lock.html`,
  `page3.html` → `photo.html`, `page4.html` → `page3.html`,
  `page5.html` → `page4.html`, `page6.html` → `page5.html`,
  `page7.html` → `page6.html`).
- 페이지 0에는 `data-prev` 가 없어서 버튼도 안 생깁니다. 페이지를 더 늘릴 땐
  `<body>` 에 `data-prev` 한 줄만 적어 주면 됩니다.
- 진행 중에 페이지 0으로 돌아가면 타이머는 계속 돌고, 시작 버튼 문구가
  `이어서 진행` 으로 바뀝니다. 그때 다시 눌러도 타이머는 초기화되지 않습니다.

> 저장소는 브라우저·기기별로 따로입니다. 진행 노트북과 참가자 노트북이 다르면
> 타이머도 따로 돕니다.

## 비밀번호 바꾸기

`lock.html` 의 `<input>` 에 있는 `pattern` 값 **한 곳**만 고치면 됩니다.

```html
<input class="field__input" type="password" pattern="0721" ...>
```

현재 비밀번호는 `0721` 입니다. 숫자·영문 모두 됩니다 (`pattern="bluesky"`).
자리수를 바꾸면 `lock.html` 아래쪽 힌트 문구(`힌트 · 네 자리 숫자`)도 같이 고쳐 주세요.

자리수는 `pattern` 길이를 보고 `game.js` 가 알아서 맞춥니다. 여섯 자리로 바꾸면
입력칸도 여섯 자까지만 받고, 경고 시점도 여섯 자 기준으로 따라갑니다. **고칠 곳은 `pattern` 한 군데뿐입니다.**

동작 방식:

- 맞으면 → `photo.html` 로 넘어갑니다.
- **자리수를 다 채우고 확인(→)이나 Enter 를 눌러 틀렸을 때만** 입력칸이 빨갛게
  흔들리고 "비밀번호가 올바르지 않습니다. 다시 시도하세요." 가 뜹니다.
- 다시 한 글자라도 입력하면 경고는 바로 사라집니다.
- 자리수를 덜 채우고 눌렀을 때는 아무 반응도 하지 않습니다(경고도, 이동도 없음).
- 브라우저 기본 경고 말풍선은 `<form novalidate>` 로 껐습니다. 판정은 `game.js` 가 합니다.
- `<input>` 에 `name` 이 없어서 주소창에 비밀번호가 남지 않습니다.

> 정적 페이지라 비밀번호는 소스 보기로 확인 가능합니다. 현장 진행용이니 문제없지만,
> 참가자에게 개발자도구가 열린 노트북을 주지는 마세요.

## 이미지 넣기

| 위치 | 파일 | 고칠 곳 |
|---|---|---|
| 페이지 0 배경 | `images/cover.jpg` | `styles.css` 맨 위 `--cover` 한 줄 |
| 페이지 1 바탕화면 | `images/wallpaper.jpg` | `styles.css` 맨 위 `--wallpaper` 한 줄 |
| 페이지 1 계정 사진 | `images/avatar.jpg` | `lock.html` 의 `.avatar` 안에 `<img class="avatar__img" ...>` 추가 |
| 페이지 2 카카오톡 캡처 | `images/kakao_bulling.JPG` | `photo.html` 의 `.stage__img` — 이미 연결됨 |
| 페이지 2 오른쪽 위 말풍선 | `images/thinking.PNG` | `photo.html` 의 `.stage__note` — 이미 연결됨 |
| 페이지 4 비밀톡방 캡처 | `images/secret_talk.jpg` | `page4.html` 의 `.stage__img` — 이미 연결됨 |
| 페이지 4 오른쪽 말풍선 | `images/thinking2.jpg` | `page4.html` 의 `.stage__note` — 이미 연결됨 |

**페이지 0에 어두운 배경 사진을 넣는 경우**: 지금은 흰 배경 기준이라 글씨가 진한 색입니다.
`styles.css` 맨 아래쪽 `--- 어두운 배경 사진을 넣을 때 ---` 주석 블록을 풀면
제목·문구·엠블럼이 밝은 색으로 바뀌고 반투명 어두운 막이 깔립니다.

바탕화면 사진이 어두워도 로그인 패널이 흰 카드라서 글씨는 그대로 잘 보입니다.

**페이지 2·4** 는 같은 배치(`.stage`)를 씁니다. 배경은 검은색이고,
세로 캡처(`.stage__img`)와 가로 말풍선(`.stage__note`)을 가운데에 나란히 놓습니다.
둘 다 자기 자리(화면 폭의 절반) 안에서만 커지기 때문에 창 크기가 바뀌어도 서로
겹치지 않고, 비율도 그대로 유지돼 잘리거나 늘어나지 않습니다. 남는 자리는 검은
배경 그대로 보입니다.

두 이미지의 몫을 다르게 나누고 싶으면 `styles.css` 의 `.stage__img` / `.stage__note`
에 있는 `max-width`(각 46vw)를 조정하면 됩니다. 단 **두 페이지가 같은 규칙을 공유**하므로,
한쪽만 다르게 하려면 클래스를 나눠야 합니다.

**페이지 3** 은 사진이 아니라 CSS로 그린 카카오톡 채팅방 + iOS 팝업입니다.
아래 "페이지 3 — 비밀 대화방" 항목을 보세요.


## 페이지 3 — 비밀 대화방 (잠금)

사진 없이 CSS만으로 그린 목업입니다: 휴대폰 프레임(9:16) 안에 카카오톡 채팅방을
흐릿하게 깔고, 그 위에 iOS 시스템 알림창 모양으로 비밀번호 입력창을 띄웠습니다.

- **비밀번호를 바꾸려면** `page3.html` 의 `<input pattern="1225">` 한 곳만 고치면
  됩니다. 자리수도 `lock.html` 과 똑같이 `game.js` 가 `pattern` 길이를 보고 자동으로 맞춥니다.
- 동작 방식도 `lock.html` 과 동일합니다 — **자리수를 다 채우고 `확인`(또는 Enter)을
  눌러 틀렸을 때만** 입력칸이 빨갛게 흔들리고 경고가 뜨고, 맞으면 `page4.html` 로 넘어갑니다.
  (같은 판정 로직을 그대로 재사용한 것이라, `lock.html` 의 비밀번호 동작을 고치면
  이쪽 규칙도 같이 바뀌는 건 아니고 완전히 독립적입니다 — 두 페이지 비밀번호는 다르게 둬도 됩니다.)
- `취소` 버튼은 페이지 2로 돌아갑니다(왼쪽 아래 `이전으로` 와 같은 목적지).
- 흐릿하게 보이는 채팅 말풍선들은 실제 대화 내용이 아니라 CSS로 그린 자리표시자입니다.
  채팅방 이름(`🔒 비밀 대화방`)이나 말풍선 배치를 바꾸려면 `page3.html` 을 직접 고치면 됩니다.
- 휴대폰 크기는 화면 높이 기준(`min(82vh, 660px)`)으로 잡혀 있어서, 노트북처럼
  가로가 넓고 세로가 짧은 화면에서도 항상 화면 안에 들어옵니다.

## 페이지 5 — 마지막 정답

- **정답을 바꾸려면** `page5.html` 의 `<input pattern="전국청소년미디어교육">` 한 곳만
  고치면 됩니다. 한글도 그대로 씁니다(브라우저가 `pattern` 을 정규식으로 읽는데,
  한글은 글자 그대로 취급돼서 문제없습니다 — 실제 브라우저에서 확인했습니다).
- 앞의 비밀번호 화면들과 달리 **입력 길이를 제한하지 않았습니다.** 자리수를 막아
  두면 정답이 몇 글자인지 알려주는 셈이 되기 때문입니다. 대신 뭐라도 입력하고
  `→`(또는 Enter)를 눌러 틀리면 바로 경고가 뜨고, 다시 입력하면 사라집니다.
- 띄어쓰기가 들어가면 오답 처리됩니다. 그래서 카드 아래에 회색으로
  `띄어쓰기 없이 입력하세요` 를 적어 뒀습니다 (`page5.html` 의 `.panel__hint`).
- 정답창은 비밀번호가 아니라 답을 적는 곳이라 `type="text"` 로 뒀습니다 —
  한글 입력 중에 자기가 뭘 쳤는지 보여야 하기 때문입니다.

## 페이지 6 — 범인 지목

검은 배경에 `범인은 이중에 있다` 가 명조체로 크게 떠오르고, 이어서 코끼리 카드
네 장이 2×2로 따라 나옵니다.

- **입장 연출**은 CSS 애니메이션입니다. 흐릿하고 자간이 넓게 벌어진 글자가
  또렷하게 모이며 떠오른 뒤(1.5초), 카드가 뒤따라 올라옵니다.
  속도를 바꾸려면 `styles.css` 의 `accuseTitleIn` / `suspectsIn` 을 고치세요.
- **글씨체**는 `--font-serif`(명조 계열)입니다. 폰트 파일을 새로 받지 않고
  mac(AppleMyungjo)·Windows(바탕)에 이미 있는 글꼴을 순서대로 시도합니다.
- **코끼리 도안은 페이지 0과 같은 것**입니다. `<symbol>` 로 한 번만 정의해 두고
  카드 네 곳에서 가져다 쓰며, 색만 카드별 `--elephant` / `--elephant-deep` 로
  갈아 끼웁니다. 도안을 고치면 네 장이 한꺼번에 바뀝니다.
- **범인을 바꾸려면** `page6.html` 에서 `data-correct` 와 `data-next` 두 속성을
  다른 카드로 옮기면 됩니다. 지금은 초록 코끼리에 붙어 있습니다.
- 맞히면 **타이머가 그 자리에서 멈추고** `page7.html` 로 넘어갑니다. 최종 기록이
  위쪽에 그대로 떠 있습니다.
- 틀리면 카드가 한 번 흔들리고 `범인이 아니다` 팝업이 뜹니다. `다시 선택` 을
  누르면 닫히고 계속 고를 수 있습니다.

> 카드 순서는 `page6.html` 의 `<button>` 순서 그대로입니다. 지금은 요청하신 순서
> (초록·분홍·주황·보라)라 정답이 맨 앞에 있는데, 순서를 섞고 싶으면 `<button>`
> 블록 위치만 바꾸면 됩니다.

## 페이지 7 — 탈출 성공

범인을 맞히면 오는 화면입니다. **어떤 내용이 들어갈지 전달받지 못해 최소한으로만
만들어 뒀으니** 문구든 구성이든 자유롭게 바꾸세요.

## 로컬에서 보기

**반드시 정적 서버로 띄우세요.** 파일을 더블클릭해서 여는 `file://` 방식에서는
브라우저가 저장소를 막는 경우가 있어 타이머가 유지되지 않을 수 있습니다.

```
npx serve .
```

배포된 주소(https)에서는 문제없습니다.

## Vercel 배포

설정 파일이 필요 없습니다. 프레임워크는 **Other**, 빌드 명령은 비워 두면 됩니다.

```
npx vercel        # 미리보기
npx vercel --prod # 실제 배포
```

또는 GitHub 저장소에 올린 뒤 Vercel 대시보드에서 Import 해도 그대로 뜹니다.

## 진행 메모

- 노트북 화면(1280×800 ~ 1440×900) 기준으로 맞췄습니다. 세로 760px 이하에서는 여백이 줄어듭니다.
- 상태 표시줄 시각 `11월 12일 (화) 02:47` 은 연출용 고정값입니다 (시계가 돌면 JS가 필요해서 일부러 멈춰 뒀습니다).
- 메뉴는 없고, 왼쪽 아래 `이전으로` 와 위쪽 `초기화` 두 개가 전부입니다.
- 다음 팀을 받을 땐 `초기화` → 확인. 시작 화면으로 돌아가면서 타이머가 0이 됩니다.
- 키오스크처럼 쓰려면 브라우저를 전체화면(F11 / ⌃⌘F)으로 두면 됩니다.
